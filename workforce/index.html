Календарь, фонд рабочего времени и сменность участков

Один и тот же календарь используется дважды: чтобы понять, сколько часов даёт один человек в месяц (фонд времени → штат) и сколько часов работает один станок/пост (загрузка оборудования, вкладка «Аналитика»). Изменение «Рабочих дней» или «Смены» здесь автоматически двигает предпросчёт обоих справа.

Фонд времени в усиленном режиме (то же звено, длиннее вахта)

Когда участок/бригада переходит на удлинённую смену (график 5/2 сохраняется) — человек физически даёт больше часов в месяц. Система применяет этот фонд вместо обычного именно для тех месяцев, где по трудоёмкости требуется усиленный режим — по конкретному участку и по пулу универсалов. Все поля остаются редактируемыми вручную — кнопки «↺» лишь предлагают значение.

Загрузка оборудования — правило рекомендации смены

Для каждого станка/поста система сама считает, сколько часов в сутки он должен фактически отработать (с учётом «Станков» и «Звено» из справочника выше), и напрямую предлагает длину смены — с шагом 0.5ч, без промежуточных «1/2 смены». Потолок — минимум из «Смена, усиленный режим» (общий предел по усталости) и «Доступность оборудования» конкретного участка (задаётся в его строке справочника, по умолчанию 24ч — то есть без отдельного ограничения).

Пример при доступности станка 24ч (без спец. ограничения)
Норма, без изменений до 8ч/сутки
Рекомендация смены (шаг 0.5ч) 8–12ч/сутки
Перегруз — не хватает поста свыше 12ч/сутки

Пересчитывается сразу при изменении параметров выше. Проверить, как это выглядит для конкретных участков — вкладка «Аналитика» → «Загрузка оборудования».
