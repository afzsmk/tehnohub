# ТЕХНОХАБ ЗСМК • Цифровая система планирования производства

Интегрированный комплекс веб-приложений для металлообрабатывающего производства и выпуска фасадных/сотовых конструкций завода ООО «ЗСМК». 

Система работает на статической платформе **GitHub Pages**, использует бессерверную СУБД **Supabase (PostgreSQL)** и состоит из двух связанных уровней управления:
1. **`workforce/`** — тактический баланс ресурсов и персонала (уровень S&OP / RCCP, помесячный горизонт 2–12 мес.).
2. **`scheduler/`** — сменно-суточный диспетчер цеха (уровень MES-lite / Finite Capacity Scheduling, горизонт 1–30 дней).

---

## 🛠 Технологический стек

* **Сборка и компиляция:** [Vite](https://vitejs.dev/) + [TypeScript](https://www.typescriptlang.org/) (ES2022).
* **База данных и Auth:** [Supabase](https://supabase.com/) (PostgreSQL + Row-Level Security).
* **Тестирование ядра:** [Vitest](https://vitest.dev/) (автоматический прогон Unit-тестов перед каждым деплоем).
* **CI/CD:** GitHub Actions (автоматическая многопроектная сборка в ветку `gh-pages`).
* **Библиотеки:** `ExcelJS` (многолистовой экспорт и парсинг), `Chart.js` (диаграммы), `html2canvas` (снимки экрана).
